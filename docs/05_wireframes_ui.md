## 1. لغة التصميم والهوية البصرية (Design System & Aesthetics)

لتقديم واجهة مستخدم مبهرة (WOW Effect) وعالية الجودة للمنصة، تم تحديد المعايير البصرية التالية:

### 1.1 الخطوط (Typography)
- **العربية:** خط **Cairo** أو **Tajawal** (من Google Fonts) لقابلية القراءة الممتازة في الأرقام والنصوص الطبية.
- **الإنجليزية:** خط **Inter** أو **Outfit** للمظهر العصري والأرقام المالية والتقارير.

### 1.2 نظام الألوان المزدوج (Dual Color System)

لتجنب الإرهاق البصري للأطباء والموظفين الذين يعملون أمام الشاشات لساعات طويلة، يدعم النظام **وضعين بصريين** يعتمدان على ألوان هادئة وخفيفة غير مزعجة للعين:

#### 🟢 الوضع المضيء الهادئ (Calm Light Mode) - *الافتراضي للمكاتب والاستقبال*
يعتمد على درجات **الرمادي الرصاصي الفاتح الناعم (Soft Slate Grey)** بدلاً من الأبيض الناصع المجهد للعين:
- **خلفية النظام (Background):** `#F8FAFC` (رمادي صخري خفيف جداً يمنع انعكاس الضوء).
- **الأسطح والكروت (Surface):** `#FFFFFF` مع حواف ناعمة جداً وظل خفيف بلون `#E2E8F0`.
- **الخطوط والنصوص الأساسية:** `#334155` (رمادي داكن مريح للقراءة بدل الأسود الحاد).
- **الخطوط الفرعية والتسميات:** `#64748B` (رمادي متوسط).
- **الحدود والفواصل (Borders):** `#E2E8F0` (رمادي فاتح هادئ).

#### 🔵 الوضع الداكن الأنيق (Sleek Dark Mode) - *المفضل للأطباء في غرف الفحص*
يعتمد على درجات الأزرق الليلي والرمادي الداكن:
- **خلفية النظام (Background):** `#0F172A` (أزرق ليلي عميق ومظلم).
- **الأسطح والكروت (Surface):** `#1E293B` (أزرق رمادي ناعم).
- **الخطوط والنصوص الأساسية:** `#F8FAFC` (أبيض كريمي خفيف مريح للعين).
- **الخطوط الفرعية والتسميات:** `#94A3B8` (رمادي فاتح).
- **الحدود والفواصل (Borders):** `#334155` (رمادي داكن).

#### 🎨 الألوان الوظيفية (Functional Colors) - *مشتركة ومخففة لمنع التشتيت*
تم اختيار درجات ألوان وظيفية هادئة (Muted Pastels) لتجنب الألوان الفاقعة المزعجة:

| نوع الحالة | اللون الوظيفي | كود الـ Hex | استخدامه في النظام |
|------------|---------------|-------------|---------------------|
| **الأساسي (Primary)** | أخضر تيل ناعم (Muted Teal) | `#0F766E` | الأزرار النشطة والقوائم الرئيسية |
| **التحذير (Warning)** | برتقالي خردلي دافئ (Warm Amber) | `#D97706` | التنبيه بالتعارض وحالات الأوفلاين |
| **الخطر (Danger)** | أحمر مرجاني هادئ (Muted Coral) | `#E11D48` | حالات الطوارئ ووقف البوت |
| **النجاح (Success)** | أخضر عشبي مريح (Sage Green) | `#059669` | تأكيد الدفع وإتمام الكشف |
| **البوت (Secondary)** | بنفسجي لافندر خفيف (Lavender) | `#4F46E5` | مؤشرات عمل البوت والشات |

### 1.3 التأثيرات البصرية (Visual Effects)
- **Glassmorphism:** استخدام خلفيات شبه شفافة مع تأثير ضبابي `backdrop-filter: blur(12px)` في القوائم الجانبية والنوافذ المنبثقة (Modals) يعطي عمق بزيادة انسيابية للعين.
- **Soft Transitions:** جميع حركات التنقل وتغيير الحالات تتم بفاصل زمني `transition: all 0.3s ease` لمنع الحركة المفاجئة المزعجة للعين.
- **Subtle Micro-animations:** حركة انسيابية للأزرار عند التمرير (Hover) وحركة نبضية خفيفة (Pulse) للـ WebSockets عند استلام رسائل أو نداء مريض.

## 2. شاشات لوحة تحكم مشغل النظام (Platform Owner Dashboard)

---


### 2.1 شاشة تسجيل الدخول والتحقق الثنائي (Admin Login & 2FA)
- **الهيكل:** واجهة مقسومة إلى نصفين (نصف أيسر يعرض رسوم متحركة ثلاثية الأبعاد تعبر عن منصة ذكية، ونصف أيمن يحتوي على فورم الدخول).
- **المكونات:**
  1. شعار المنصة بلمعان خفيف (Gradient Logo).
  2. حقل البريد الإلكتروني وكلمة المرور.
  3. زر "تسجيل الدخول" بتأثير Loading عند الضغط.
  4. **شاشة الـ 2FA البديلة (تظهر بعد إدخال البيانات صحيحة):** 6 خانات لإدخال كود OTP، مع رسالة "تم إرسال كود التحقق على رقم الواتساب الخاص بك ينتهي خلال 5 دقائق". زر "إعادة إرسال" يظهر بعد دقيقة.

---

### 2.2 لوحة إحصائيات المنصة (Platform Overview)
تمنح مشغل النظام لمحة سريعة عن أداء البيزنس والمبيعات.
- **توزيع العناصر (Grid Layout):**
  - **الصف العلوي (4 كروت أرقام رئيسية):**
    - كرت **إجمالي الإيرادات المتكررة شهرياً (MRR):** رسم بياني خطي صغير متناهي الصغر (Sparkline) يوضح نمو الأرباح.
    - كرت **العيادات النشطة:** (العدد الإجمالي مع نسبة الزيادة الأسبوعية).
    - كرت **حجم محادثات البوت:** (عدد الرسائل التي تمت معالجتها اليوم).
    - كرت **معدل الحجوزات الناجحة أونلاين:** (نسبة التحويل العامة للمنصة).
  - **الصف الأوسط:**
    - **رسم بياني كبير (Area Chart):** نمو الحجوزات اليومية مقارنة بالدفع الأونلاين والكاش.
    - **قائمة العيادات الأكثر نشاطاً:** مرتبة حسب عدد الحجوزات واستخدام البوت.
  - **الصف السفلي:**
    - **لوحة تتبع استهلاك الموارد:** (استهلاك مساحة التخزين للصور والمستندات، حالة اتصال خوادم الـ Webhook مع Meta).

---

### 2.3 إدارة العيادات والاشتراكات (Tenant Management)
- **المكونات:**
  1. جدول ذكي يدعم الفلترة السريعة (نشط، معطل، تجريبي، منتهي الاشتراك) وحقل بحث شامل.
  2. أعمدة الجدول: [اسم العيادة - التخصص - الطبيب المالك - خطة الاشتراك - تاريخ الانتهاء - عدد المرضى - حالة الواتساب - العمليات].
  3. **العمليات المتاحة لكل عيادة:**
    - زر **تفاصيل الاستخدام:** يفتح لوحة جانبية (Slide-over Panel) تعرض استهلاك البيانات بالتفصيل وآخر دخول للموظفين.
    - زر **إدارة الاشتراك:** نافذة منبثقة لتغيير الخطة (Upgrade/Downgrade) أو تمديد المدة يدوياً.
    - زر **إعادة تعيين كلمة المرور:** لتوليد رابط استعادة للطبيب وإرساله تلقائياً.
    - مفتاح تفعيل/تعطيل (Toggle Switch): لتعطيل الخدمة عن العيادة فوراً مع تدوين السبب.

## 3. شاشات لوحة تحكم الطبيب (Doctor Dashboard)

---

### 3.1 شاشة غرفة الكشف والسجل الطبي الرقمي (Clinical SOAP & EMR)
هذه هي الشاشة الأكثر استخداماً من الطبيب. مصممة لتكون خالية من التشتيت (Distraction-Free) وتدعم الكتابة السريعة.

```
+--------------------------------------------------------------------------+
|  👨‍⚕️ د. محمد النور | مريض نشط: أحمد محمد حسن (32 سنة) | كشف جلدية وتجميل       |
+--------------------------------------------------------------------------+
|  [S] Subjective (شكوى المريض والتاريخ)  |  [O] Objective (الفحص السريري)   |
|  +-----------------------------------+  |  +---------------------------+  |
|  | يعاني من حب شباب شديد منذ شهرين...|  |  ضغط الدم: [120/80]  النبض: [75] |  |
|  |                                   |  |  الحرارة:  [37.0]  الوزن: [68.0] |  |
|  +-----------------------------------+  |  +---------------------------+  |
+-----------------------------------------+--------------------------------+
|  [A] Assessment & ICD-11 (التشخيص)      |  [P] Plan (الخطة العلاجية)       |
|  +-----------------------------------+  |  +---------------------------+  |
|  | التشخيص: Acne Vulgaris (L70.0)    |  |  كورس تقشير كيميائي للوجه    |  |
|  | [بحث في أكواد ICD-11...          ] |  |                             |  |
|  +-----------------------------------+  |  +---------------------------+  |
+-----------------------------------------+--------------------------------+
|  💊 الروشتة الإلكترونية الذكية (E-Prescription)                           |
|  +---------------------------------------------------------------------+  |
|  | 1. Clindamycin Gel | دهان مرتين يومياً | 14 يوم | بعد غسل الوجه      |  |
|  | 2. [ ابحث عن دواء أو اكتب هنا...                                   ] |  |
|  +---------------------------------------------------------------------+  |
|  [+] إضافة دواء    [📸 صور الزيارة (قبل/بعد)]    [💾 حفظ واعتماد الروشتة] |
+--------------------------------------------------------------------------+
```

- **تخصيص الواجهة حسب التخصص:**
  - **إذا كان التخصص تجميل وجلدية:** يظهر كرت جانبي لرفع الصور (Upload Container) مع أداة رسم ويب (Canvas Drawing) على مخطط للوجه لتحديد نقاط حقن الفيلر/البوتوكس وعدد الوحدات.
  - **إذا كان التخصص أسنان:** يظهر جدول الأسنان التفاعلي (Odontogram) بنظام FDI حيث يمكن للطبيب الضغط على أي سن واختيار حالته (تسوس، حشو، مفقود) ليتم حفظها مباشرة في الـ Database.

---

### 3.2 لوحة التحليلات المالية وتشغيل البوت (Clinic Analytics)
تظهر فقط للطبيب (صاحب العيادة) لخصوصية البيانات.
- **الرسوم البيانية المتضمنة:**
  1. **مخطط الدخل الإجمالي (Bar Chart):** مقسم حسب طريقة الدفع (Cash vs Visa vs Mobile Wallet).
  2. **مخطط الـ No-Show Rate:** مقارنة دائرية بين المرضى الذين حجزوا أوفلاين كاش (ولم يحضروا) والمرضى الذين دفعوا أونلاين عبر البوت (ولم يحضروا)، لإثبات الجدوى الاقتصادية لخصم الدفع الإلكتروني.
  3. **معدل تحويل البوت (Funnel Chart):**
     - عدد المحادثات التي بدأت ← عدد المرضى الذين اختاروا موعداً ← عدد الفواتير الصادرة ← عدد الحجوزات المؤكدة (المدفوعة).

## 4. شاشات لوحة تحكم السكرتاريا (Secretary Dashboard)

---

### 4.1 صندوق الوارد الموحد والتدخل اليدوي (Omnichannel Inbox)
مصمم للتعامل السريع مع محادثات المرضى الواردة من الواتساب.

```
+--------------------------------------------------------------------------+
|  🔍 بحث في المحادثات... | محادثة: محمد أحمد حسن [ البوت: 🟢 نشط | 🔴 إيقاف ] |
+-----------------------------------+--------------------------------------+
| [🔴 تعارض] سارة علي (منذ 2 د)      | (المريض): سعر جلسة الفيلر كام؟       |
| "حجز مزدوج الساعة 10:00"          | (البوت): سعر الجلسة 1500 جنيه.       |
|                                   |--------------------------------------|
| محمد أحمد حسن (منذ 5 د)           | (المريض): تمام عايز أحجز مع الدكتور. |
| "تمام عايز أحجز مع الدكتور..."    | (البوت): يرجى اختيار الميعاد المناسب:|
|                                   | [الأربعاء 10:00] [الخميس 11:30]     |
| محمود سعيد (منذ 1 ساعة)           |--------------------------------------|
| "تم تأكيد الدفع بنجاح"            | (المريض): المواعيد دي مش مناسبة لي   |
|                                   | (المريض): في مواعيد مسائية؟          |
+-----------------------------------+--------------------------------------|
|                                   | [  اكتب رسالة للرد اليدوي هنا...   ] |
|                                   | [📎 إرفاق ملف]           [💬 إرسال] |
+--------------------------------------------------------------------------+
```

- **العناصر التفاعلية بالصفحة:**
  - **زر تبديل حالة البوت (Toggle Switch):** بجانب اسم المريض، عند كتابة السكرتير لأي رسالة يدوية، يتحول المفتاح تلقائياً لـ **"🔴 إيقاف (وضع يدوي)"** ويظهر مؤقت تنازلي (60 دقيقة).
  - **بادج التنبيه بالتعارض [🔴 تعارض]:** يظهر في قائمة الدردشة إذا كان هناك تعارض أوفلاين/أونلاين معلق لهذا المريض يحتاج لحل.

---

### 4.2 التقويم الذكي وحل نزاعات الحجز (Calendar & Sync Conflicts)
- **شاشة التقويم (Calendar View):**
  - عرض المواعيد بنظام (يوم، أسبوع، شهر).
  - المواعيد المؤكدة تظهر بلون أخضر تيل (Teal).
  - المواعيد المؤقتة (قفل الدفع) تظهر بلون بنفسجي منقط مع مؤقت تنازلي حي يقل كل ثانية.
  - **شريط حل النزاعات المعلقة (Conflict Notification Banner):**
    - يظهر في أعلى الكاليندر بلون برتقالي/أحمر وامض عند وجود تعارض مزامنة أوفلاين. عند الضغط عليه يفتح واجهة المقارنة.
- **واجهة حل النزاع (Conflict Resolver Dialog):**
  - تعرض كرتين متجاورين:
    - **الكرت الأيمن (حجز السيرفر أونلاين):** "المريض: سيد محمود - الساعة 10:00 - مدفوع فيزا (Paymob)".
    - **الكرت الأيسر (الحجز المحلي أوفلاين):** "المريض: محمد أحمد - الساعة 10:00 - كاش بالعيادة".
  - **الخيارات المتاحة للسكرتير:**
    - زر [تأكيد حجز الأونلاين ونقل حجز الكاش لموعد آخر].
    - زر [تأكيد حجز الكاش وتعديل حجز الأونلاين بعد الاتصال بالمريض].
    - بمجرد الاختيار، يقوم النظام تلقائياً بإرسال رسالة واتساب تعديل الموعد للطرف الذي تم نقله.

## 5. شاشة غرفة الانتظار العامة (TV Waiting Room Display)

شاشة عامة يتم فتحها على شاشة ذكية (Smart TV) في ردهة الاستقبال، بدون أي بيانات سرية للمرضى لحماية الخصوصية.

### 5.1 المظهر والتوزيع (TV Layout)
- الخلفية داكنة تماماً (#0F172A) لتقليل إجهاد العين ووهج الشاشة في العيادة.
- الواجهة مقسومة إلى عمودين متساويين:

```
+--------------------------------------------------------------------------+
|                   عيادة النور للتجميل والجلدية                           |
+------------------------------------+-------------------------------------+
|   👉 المرضى داخل غرفة الكشف حالياً  |       📋 قائمة الانتظار القادمة      |
|                                    |                                     |
|  +------------------------------+  |  +-------------------------------+  |
|  |  رقم [ 12 ] : أحمد محمد      |  |  |  رقم [ 14 ] : سارة علي         |  |
|  |  مع: د. محمد النور           |  |  |  رقم [ 15 ] : محمود سعيد       |  |
|  +------------------------------+  |  |  رقم [ 16 ] : هالة عبد الله    |  |
|                                    |  |  رقم [ 17 ] : كريم أحمد        |  |
|                                    |  +-------------------------------+  |
+------------------------------------+-------------------------------------+
|  الرجاء تحضير كود الحجز الخاص بك عند نداء رقمك. شكراً لتعاونكم.           |
+--------------------------------------------------------------------------+
```

### 5.2 التفاعلات والـ Real-time
1. **صوت التنبيه (Chime Alert):** عندما يضغط الطبيب على زر "المريض التالي"، تصدر الشاشة صوتاً تنبيهياً مميزاً (Ding-Dong Chime) لجذب الانتباه.
2. **الأنيميشن (Visual Cue):** الكرت الخاص بالرقم الجديد الذي تم ندائه يومض (Flashing Border) باللون الأخضر لمدة 5 ثوانٍ مع تكبير حجم الخط تلقائياً لتسهيل القراءة لكبار السن.
3. **تحديث البيانات:** يتم تحديث الجدول بالكامل في غضون أجزاء من الثانية دون عمل Reload للصفحة باستخدام الـ WebSockets.
4. **حماية الخصوصية:** يتم عرض **الاسم الثنائي** للمريض فقط (مثال: "أحمد محمد" بدلاً من "أحمد محمد حسن عبد الرحمن").
